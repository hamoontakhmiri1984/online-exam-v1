# تمرین و مرور

مدرس از سؤال‌های بانک‌های خودش یک مجموعهٔ تمرین می‌سازد، گروه‌های خودش را انتخاب می‌کند و پس از بازبینی آن را منتشر می‌کند. ذخیرهٔ پیش‌نویس به معنی انتشار نیست. کارآموز فقط تمرین منتشرشدهٔ گروه‌هایی را می‌بیند که عضو آن‌هاست. مدیر ارشد دسترسی مشاهده دارد.

تمرین محدودیت زمانی و نمرهٔ آزمون ندارد. پاسخ صحیح پس از ثبت پاسخ نمایش داده می‌شود. هر بار «دوباره تمرین می‌کنم» یک تلاش تازه است؛ تکرار درخواست شبکه با همان شناسه، تلاش تازه محسوب نمی‌شود. شمارندهٔ درست و غلط، آخرین نتیجه و تاریخچه برای هر کارآموز و هر سؤال در همان مجموعه نگهداری می‌شود؛ آمار یک سؤال در مجموعه‌های مختلف با هم ادغام نمی‌شود.

سؤال‌ها هنگام ساخت مجموعه کپی می‌شوند. ویرایش یا حذف سؤال اصلی، سؤال تمرین و سوابق آن را عوض نمی‌کند. بعد از اولین انتشار، سؤال‌های مجموعه ثابت می‌مانند؛ برای تغییر آن‌ها مجموعهٔ تازه بسازید. عنوان، توضیحات و گروه‌ها قابل ویرایش‌اند. توقف دسترسی، مجموعه را از دید کارآموز خارج می‌کند ولی سابقه را حذف نمی‌کند. حذف عضویت گروه نیز دسترسی به تمرین و سابقهٔ آن را قطع می‌کند.

در انتخاب سؤال برای آزمون، سؤال‌هایی که در مجموعهٔ تمرین منتشر شده‌اند هشدار دارند. این هشدار مانع انتخاب نیست. مسیرهای موجود ساخت سؤال دستی، اکسل و بانک برای آزمون حفظ شده‌اند.

## راه‌اندازی در Codespaces

پس از اعمال پچ، با سرویس PostgreSQL روشن، از پوشهٔ server اجرا کنید:

```bash
npx prisma generate &&
npx prisma migrate deploy &&
REQUIRE_SERVICES=1 node --test tests/practice.test.cjs tests/practice.integration.test.cjs &&
npm run build
```

مهاجرت فقط جدول‌ها و روابط جدید تمرین را اضافه می‌کند. از `migrate reset` استفاده نکنید. سرور در حال اجرا را پس از این مرحله دوباره راه‌اندازی کنید.

از ریشهٔ پروژه:

```bash
npm test -w client &&
npm run build -w client &&
npm run lint -w client
```

تست اتصال واقعی با DATABASE_URL در server/.env اجرا می‌شود و داده‌های آزمون را با شناسه‌های تصادفی ایجاد و پاک می‌کند. REQUIRE_SERVICES=1 مانع رد شدن خاموش تست در نبود دیتابیس می‌شود. CI نیز پس از اجرای مهاجرت‌ها این تست را اجرا می‌کند.

## بازبینی دستی

1. مدرس: تمرین تازه با دو سؤال و یک گروه بسازید؛ پیش‌نویس نباید برای کارآموز دیده شود.
2. منتشر کنید؛ عضو همان گروه باید دسترسی داشته باشد و عضو گروه دیگر نباید دسترسی داشته باشد.
3. یک پاسخ درست و یک پاسخ غلط ثبت کنید؛ صفحه را رفرش کنید و سابقه و شمارنده‌ها را بررسی کنید.
4. تمرین را متوقف کنید؛ دسترسی کارآموز قطع می‌شود. با انتشار دوباره، سابقه باقی است.
5. حالت روشن، تاریک و صفحهٔ موبایل را بررسی کنید؛ سطح سؤال علاوه بر رنگ با متن مشخص است.
